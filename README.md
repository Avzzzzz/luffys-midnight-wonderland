# Luffys Midnight Wonderland

Build a fully animated, interactive, multi-section romantic birthday website for my boyfriend, Arshmeet Singh. His online gaming name is Luffy.

The website should feel like a magical little universe created by his girlfriend, not a generic birthday template.

**IMPORTANT:** Do not make this a simple scrolling landing page. I want a proper interactive experience with multiple screens, transitions, clickable objects, animations, hidden surprises, and a beautiful emotional ending.

### 1. Overall design and aesthetic

Theme: Dreamy romantic midnight universe mixed with cute anime aesthetics.

Color palette:
- Midnight navy: #171A35
- Dusty lavender: #C7B6E8
- Soft blush pink: #F6DCE7
- Warm cream: #FFF5E9
- Pale moonlight: #E8E7FF

Visual elements:
- Glowing crescent moons.
- Tiny animated stars and constellations.
- Cute cats sleeping on clouds.
- Floating hearts and sparkles.
- Cherry blossoms and little flowers.
- Animated shooting stars.
- Handwritten-style typography.
- Cute paper textures, scrapbook cards and envelopes.

Use beautiful fonts such as Cormorant Garamond for emotional headings and DM Sans or Quicksand for body text.

The website must be responsive, especially for mobile phones.

### 2. Opening screen – A little invitation

Create a beautiful midnight sky with an animated crescent moon, twinkling stars and a tiny cat sitting on the moon.

In the center:

"Hey, Luffy! 🌙"

"I made a little universe for someone special."

Below it, a glowing button:

[ Enter your little universe ♡ ]

When clicked:
- The moon should glow.
- Stars should scatter.
- The screen should transition smoothly into the next scene.

Add subtle background music with a visible mute/unmute button. Music must start only after the visitor interacts with the page.

### 3. The key collection – Unlock your surprises

Create an interactive screen with three adorable floating keys.

Each key should have a different design:
- Moon key 🌙
- Heart key ♡
- Cat key 🐈

Heading:

"Before you enter, you have three little things to discover..."

Each key should unlock a different surprise when clicked.

Use smooth unlocking animations, glowing effects and little sound effects.

### 4. Surprise cards – Little things about us

Create three beautiful interactive scrapbook-style cards.

**Card 1: How this little story started**

Create an anime-inspired gallery dedicated to the anime we watched together:

Use soft cherry blossom visuals, romantic anime-inspired backgrounds and subtle floral animations.

Include the text:

"Some stories are beautiful to watch, but they're even more special when you have someone to watch them with."

Do not use copyrighted anime screenshots or character artwork. Use original anime-inspired illustrations and visual motifs.

### 10. Technical requirements

- Build using React, TypeScript and Tailwind CSS.
- Use Framer Motion for smooth page transitions, interactive animations and card reveals.
- Use Lucide icons where appropriate.
- Make every interactive element functional.
- Add smooth transitions between every section.
- Add a progress indicator showing how far the visitor has travelled through the experience.
- Include a small floating music toggle.
- Include a replay button at the end.
- Make the website responsive for desktop and mobile.
- Optimize animations so the website remains smooth.
- Use reusable components and clean code.
- Avoid unnecessary gradients, excessive visual clutter and generic AI-looking designs.
- Do not use browser alerts for interactions.
- Make all text editable so I can personalize it later.
- Provide clear placeholders for uploading our actual photograph and changing the music.

**MOST IMPORTANT DESIGN INSTRUCTION:**

I want this to look like a professionally designed romantic interactive storybook, with the quality of a beautiful indie game menu mixed with an anime-inspired birthday scrapbook.

Do not put everything on one page at once. Reveal each part progressively through interactions. The experience should feel magical, playful, personal and emotional.

Build the complete working website, not just a visual mockup.

A few things to include:
- A little cat companion: Have a tiny cat follow him throughout the website that can occasionally sleep, blink, or display cute messages.
- Hidden clickable messages: Hide little messages behind stars, flowers, and objects so he can discover them.
- A special cake animation: Let him blow out the candles and reveal the letter only after he makes a wish.
